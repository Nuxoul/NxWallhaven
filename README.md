# WallHaven Studio

wallhaven.cc 的 Windows + Android 第三方客户端，目标包含本地数据管理与清洗。非官方项目，与 wallhaven.cc 无隶属关系。

## 当前状态

已确认采用方案 B：

- **Windows：Rust + Slint**，实现位于 `rust/desktop`。
- **共享核心：Rust**，当前 API、模型、限流与布局位于 `rust/core`；统一数据库及 UniFFI 待实现。
- **Android：Kotlin + Compose Multiplatform / Material 3**，尚未开始实际集成。

当前优先修复与验收 Windows 浏览、详情、设置，不代表桌面全部功能已完成。原 Gradle 骨架不是可交付的 Android 实现。

## 构建与运行

```powershell
cd D:\Code\wallhaven\rust
cargo test --workspace
cargo clippy --workspace --all-targets -- -D warnings
cargo build --release -p wh-desktop
.\target\release\wh-desktop.exe
```

配置默认保存到 `%APPDATA%\WallHavenStudio\config.json`；Windows Key 使用 DPAPI 加密。测试应使用隔离目录，不覆盖真实配置。

Windows 单文件包：`dist\WallHavenStudio-0.1.0-windows-x64\WallHavenStudio.exe`，可通过 `scripts\package-windows.ps1` 重建。静态 CRT、内嵌图标/资源，无需随附应用 DLL；当前未签名，网站登录仍需要系统 Microsoft Edge WebView2 Runtime。

图片文件缓存位于 `%LOCALAPPDATA%\WallHavenStudio\Cache\Images`，与设置中的下载目录分开。完整原图加载后保存直接复用本地原始文件字节，不再次请求、不重新编码；重启后仍可复用。设置可查看实际磁盘用量/路径并清理，下载、配置和登录资料不受影响。

## 最新修复与验收

最新改进见 [磁盘图片缓存、原图保存复用与单文件发行](docs/22-磁盘图片缓存与单文件发行.md)；此前修复见 [多窗口 UX 与原图阶段加载](docs/21-多窗口UX与原图阶段加载.md)、[原图提速、作者分级与标题对齐](docs/20-加载提速与作者筛选标题对齐.md)、[原图内存限制修复](docs/19-原图内存限制修复.md)。

- 兼容认证响应中的数字字符串，例如 `per_page: "24"`。
- 设置改为独立窗口，不缩小主窗口。
- 第一页后自动预取第二页，并在接近底部之前异步加载后续页。
- 记录真实 computer-use 操作证据、自动化检查及未验收范围。
- 新增高级筛选、详情标签/颜色搜索、复制链接、打开目录及壁纸设置接口；实测下载完成落盘。
- 网站登录改为应用内 WebView2；验证、账号确认和收藏请求复用同一浏览器会话。原生窗口及本地 Cookie 复用已验证，真实账号仍需本人完成网站安全验证，尚未端到端验收。
- 修复画廊右侧留黑与收藏侧栏偏移，增加卡片爱心快捷收藏和软件内收藏夹管理；分页/管理本地回归通过，真实账号完整列表及写入仍待本人登录后验收。
- 登录改用固定应用浏览器资料目录并在重开后核对恢复；收藏爱心仅悬停显示。原生跨进程恢复/清理测试通过，但真实账号跨重启与安全验证间歇停留仍需本人验收，不承诺绕过网站验证。
- 修复已登录“我的收藏夹”误读公开页导致私有 Default 遗漏；自己的列表和内容改用已登录专用入口，真实只读核对 Default 4 张/SFW 3 张。站内写入及间歇安全验证仍保留验收限制。
- 应用主窗口、设置和收藏弹窗统一 Fluent 深色与自绘标题栏；原生拖动、边缘缩放、双击最大化、最小化/还原、独立窗口关闭及关键页面已做本机实测。WebView2 网站登录窗口保留系统标题栏。
- 继续修正筛选表单大空隙、导航层级、空状态底栏、详情缺失值与设置操作间距；保留原图比例、悬停收藏和独立窗口行为。
- 点击图片上传者打开独立 Slint 原生主页，包含公开资料、上传作品及公开收藏；分级继承主界面，可独立筛选 SFW/Sketchy/获准的 NSFW。作品/收藏自动追加续载，完整原图使用独立详情窗口，不重置主列表。
- 原图加载取消固定解码内存/边长/响应大小上限和 2000px 降采样，详情继续加载完整原图；12000×8000 回归已复现旧报错并通过修复，真实详情确认完整原图尺寸。
- 原图与详情信息并行加载，最近一张原图复用共享像素；本机完整6240×4160原图重开约62ms。标题栏图标/文字统一垂直居中，实测中心差0.5px。
- 图片详情与作者主页支持多窗口并存；主画廊和作者页共用独立详情窗口，设置/收藏工具相对来源居中；原图显示传输/解码阶段、进度与重试，同图并发合并请求并共享像素。
- 图片压缩文件改为真正的磁盘缓存；加载后断网保存、独立新进程离线保存及加载中保存只发一次请求均通过回归。设置显示真实文件用量和路径，可安全清理。
- 鼠标指针锚点缩放与作者自动续载组件回归通过；本轮全量155项常规测试、严格 Clippy、格式和单文件 PE 检查通过，最终包的桌面点击验收边界见最新记录。
