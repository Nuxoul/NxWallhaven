# Windows 界面美化与自绘标题栏

## 本轮范围

用户要求完善、美化前端 UI，并改用自绘标题栏。保持 Rust + Slint Windows 架构，不改 Android，不改账号认证、内容权限或收藏写入规则。

## 视觉与布局

- 图片优先的 Fluent 深色工作台，固定 Fluent 控件与深色配色，保留 Segoe UI。基础色：画布 `#141518`、面板 `#1b1d21`、悬停 `#252830`、边界 `#343842`、强调蓝 `#79b8ff`。
- 40px 自绘标题栏与 64px 导航/搜索工具区分层，独立“发现壁纸 / 我的收藏”入口，按钮统一高度，条件创建隐藏控件避免保留空位。
- 筛选区统一间距；主画廊仍按原图比例自适应，爱心仍保持 24px 按钮、16px 图标且仅悬停出现。
- 收藏侧栏增加当前集合的选中背景和蓝色标记，刷新时根据实际集合恢复选中态，长名称按内容高度展开。
- 加载/空列表/未选择收藏夹有明确说明，状态不冒充加载成功。
- 设置按网站账号、API、浏览/下载分组，中间滚动、底部“关闭 / 保存设置”固定可见。关闭清空未保存的 Key 输入，不写配置。
- 快捷收藏、收藏夹管理使用同一标题栏与信息面板，编辑/刷新与删除危险操作分组；确认约束不变。

## 自绘窗口行为

主窗口、设置、快捷收藏、收藏管理四个 Slint 窗口 `no-frame: true`，提供可访问的最小化、最大化/还原、关闭按钮，悬停/按下/键盘焦点状态；回车与空格可触发。关闭调用 Window.close，沿用既有 close-requested 处理。主窗口关闭联动隐藏附属窗口，防止仅剩弹窗使应用不退出。

网站登录是独立 WebView2 窗口，本轮保留其系统标题栏，避免美化改动敏感的安全验证窗口。

### Windows 原生移动/缩放适配

初版使用 Slint WindowMoveArea 与 resize-border-width，组件测试通过，但真实桌面拖动/缩放均未移动。核对 Winit 0.30.13 的 Windows `handle_os_dragging`，其 WM_NCLBUTTONDOWN 坐标参数存在错误形式；未修改依赖源码。

应用增加独立 `window_chrome.rs`：仅处理 WM_NCHITTEST，将标题栏空白区域和窗口边缘返回 Windows 原生命中码，系统处理移动、双击、缩放；窗口按钮区域留给 Slint。按 DPI 换算区域、最大化时不返回缩放码，保存并转发原窗口过程，销毁时恢复/移除属性。

首次使用公共控件 subclass 接口的 Release 在桌面启动器环境报入口不可用，未交付该版；改用基础 Win32 窗口过程链，不新增安装或清理系统要求。兼容版真实启动成功。

最大化时 UIA 会暴露系统窗口元信息，不能因此认定双标题栏。实际测量客户区原点为 (0,0)，内容不额外偏移，系统样式中的 WS_CAPTION 是 Winit 支持 Windows 窗口操作的内部处理，没有据此盲目修改样式。
