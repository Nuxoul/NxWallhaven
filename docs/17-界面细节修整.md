# 界面细节修整

本轮按用户要求检查当前界面，不重做设计、不扩展业务。初评按层级、灰度、留白、标签、间距、文本宽度、对比、深度八项约 6/10；主要缺口为主次层级、表单间距与文本约束，并非宣称完成度评分。

## 发现与修改

- 主导航用了 Fluent 实心选中按钮，与“搜索”主操作竞争。改为低强调页签、短蓝色指示线，保留键盘与可访问性动作。
- “账号已连接”替代设置名称，不容易看出入口作用。改为固定“账号与设置”，连接状态用小标记，具体信息仍在设置里。
- 高级筛选短标签被布局横向拉伸：真实 UIA 测得“排序方向”宽 390px、“最小分辨率”从 x=514 开始。改为固定标签宽与紧凑控件，末尾弹性空白集中处理；隐藏自定义字段不保留空间。
- 条件布局的 preferred-height 未随额外行更新，新回归实际测到前后均为 164px。改为明确行高与附加高度，排行榜范围和可换行错误提示能增加面板高度，不覆盖图片区、不撑大 860×600 窗口。
- 收藏未选中时，中间提示“打开一个收藏夹”，底栏却写“已显示全部结果”且露出禁用的加载更多。改为未选择/空结果不显示末尾提示、加载中明确提示、非空末尾显示“已到列表末尾”，无下一页时不创建加载按钮。第 0 页不再显示“0 张 · 第 0 页”噪音。
- 详情缺失大小/浏览数被当作 0，上传者与日期等留空。改为 `—`，保留真正的零值；元数据用固定标签列与可换行值列，弱化标签、分开格式/体积。
- 设置底部关闭与保存之间无明确间距，补 8px。
- 快捷收藏已收藏/未就绪时，隐藏下拉框和登录按钮仍可能保留布局位置。改为条件创建。
- 管理窗口的未知可见性确认一勾就消失，无法取消。用独立的“原状态未知”属性控制显示，勾选后仍可撤销；后端提交保护仍要求确认。

## 检查

- 缺失文件大小回归先失败 `unknown file size was presented as 0 KB`，修复后通过。
- 组件测试覆盖紧凑标签、面板额外内容扩展、错误提示、不撑大窄窗口、空状态文案、缺失数据与真实零、未知可见性确认可撤销。原有滚动、详情返回、悬停爱心和标题栏回归继续通过。
- `cargo test --workspace`：核心 38 通过/1 忽略，桌面 78 通过/2 忽略，无失败。
- `cargo clippy --workspace --all-targets -- -D warnings`、格式检查通过。本轮没有重跑认证原生测试，也未改动认证实现。

桌面复验结果在执行后补记。本轮不保存真实设置、不更改账号或站内收藏；旧配置元数据仍为 38 字节、修改时间 2026-10-18 12:22:46 UTC。自绘标题栏底层和网站安全验证不在本轮修改范围。

## 桌面复验

- 新版筛选标签真实宽度为 60px，“最小分辨率”改到 x=204；原版分别为 390px 和 x=514，大块横向空隙已消除，输入/操作控件为 32px。
- 输入无效颜色后显示完整错误提示，原有 48 张结果仍保留；860×600 窗口下提示、应用按钮与分辨率标签均在窗口内。
- 未选择收藏夹时不再显示“第 0 页”“已显示全部结果”及禁用加载按钮；Default 4 张/私有等列表仍正常读取。
- 设置底部关闭/保存按钮实测间距 8px，关闭后主窗口保持 1280×820，未保存配置。
- 真实辅助功能检查发现新导航被识别成切换按钮，已移除误用的 checkable 声明，保留普通按钮默认动作、键盘与选中视觉；最终版再核对。

这是一次有限的细节修整，没有声称所有页面/状态已达到满分，网站安全验证和真实站内写入限制保持不变。

## 最终版核对与边界

最终 Release 已构建并启动。导航在真实 UIA 中显示 Invoke 动作，实际 `InvokePattern` 成功切换收藏页。Default 仍显示 4 张/私有，点开正常加载 3 张 SFW 图片，到末尾显示“已到列表末尾”，不再露出禁用加载按钮。详情初始列表数据中缺失的体积/格式/上传者/浏览/上传时间均真实显示 `—`，不是假零或空行；元数据采用标签/值独立列。未知可见性确认可撤销由隔离组件回归覆盖，没有为测试改变真实收藏夹的可见性。

最终全量仍为核心 38 项、桌面 78 项通过，Clippy、格式与 Release 构建通过；本轮不重新声称原生登录测试或跨屏 DPI 手测。配置保持 38 字节及原修改时间。

修整后的层级、间距和文本约束有改善，但没有完成全量辅助功能/对比度及跨屏审核，因此不标为 10/10。主观八项复评约 8/10，剩余跨 DPI 与完整状态视觉检查不作通过声明。网站安全验证间歇问题仍未在本轮解决。
