# 登录保留、悬停收藏与安全验证状态

## 这次反馈与原因

1. 旧版网页会话使用每次随机的临时 WebView2 目录，关闭后不复用且尝试删除，导致“重开软件就未登录”。这是程序实现缺口，不是 API Key 丢失。
2. 爱心虽已缩小，但没有悬停显示条件，所有卡片常驻显示。
3. 网站有概率长时间显示安全验证页。本轮没有确定其间歇性停留的全部原因，不能把保留 profile 或增加重载入口冒充网站验证已彻底解决。

## 修改

### 网站登录资料保留

- 改用本应用独立固定目录 `%LOCALAPPDATA%\WallHavenStudio\WebView2`，不读取或复用系统 Edge/Chrome 资料目录。
- 隔离运行时 `WH_STUDIO_CONFIG_DIR` 下使用 `webview-profile`，自动化只访问自己新建的测试目录。
- 正常关闭保留 WebView2 资料，主程序退出时显式通知浏览器线程正常关闭并等待完成。
- 不导出 Cookie，不保存密码，禁用 WebView2 密码自动保存和表单自动填充。网站请求继续在同一 WebView2 内发送。
- 固定目录占用锁防止多个程序窗口同时写；资料标记仅表示“可尝试恢复”，不表示账号已登录。
- 重开后后台读取网站用户面板，网站返回账号与登出证据后才启用收藏。验证页、过期和网络错误不会被当作登录成功；保留原浏览器供本人继续。
- 明确的“退出并清除登录数据”调用 WebView2 当前 profile 的异步清理 API，等待完成回调，成功后清除应用状态。失败会提示“退出尚未确认”，不会谎报已退出。该操作只清理本应用的站点资料，不改 API Key、不操作网站账户。

**网站有效期边界：**固定资料目录保留持久 Cookie 和网站存储，不能强行把网站的 session Cookie 改成永久 Cookie。网站若提供“记住我”需本人选择；过期、撤销或安全验证仍可要求重新登录。旧版随机临时会话不会自动迁移到新目录，因此升级后首次仍需登录。

### 爱心交互

- 24×24px 小按钮、16px 图标保持不变。
- 默认隐藏；鼠标移入卡片后显示；移到爱心上仍显示；移出后隐藏。
- 隐藏时不拦截图片点击，显示时爱心和详情点击仍独立。
- 组件鼠标回归先在旧逻辑失败 `favorite remains clickable without hovering the card`，修正后覆盖移入、独立点击和移出隐藏。

### 安全验证

- 源码核对：Wry 0.57 Windows 的 navigation handler 注册主框架 `NavigationStarting`，不是 iframe/子资源过滤器。因此不能声称此前同源限制拦住了 Cloudflare 验证 iframe；没有据此放宽安全限制。
- 保留正常 WebView2 User-Agent，没有伪造浏览器指纹、关闭自动化检测、修改 Cookie 生命周期或自动完成验证码。
- 检测到验证页时显示“网站仍在安全验证，并非已登录”。轮询只读用户面板，不重复提交登录或收藏。
- 新增“验证卡住？重新加载登录页”，仅本人点击时在同一会话重载；不会自动循环刷新、不会新建另一份 profile。原确认等待已超时的情况下会恢复只读确认。
- 本轮更新前只读观察，旧版登录窗口已经显示正常的用户名/密码登录表单，证明该问题具有间歇性；这不是本轮修复后通过安全验证的证据。

## 自动化验证

- `cargo test --workspace`：核心 38 通过、1 忽略；桌面 74 通过、2 忽略，无失败。
- `cargo test -p wh-desktop native_webview_session -- --ignored --nocapture`：通过，测试启动自己的本地 HTTP 站点和临时 profile。
  - 同一浏览器隐藏/重开、Cookie 复用和中文表单、CSRF、POST 次数检查。
  - 正常关闭后由**独立子进程**使用相同 profile，读取到已登录面板；再在新 WebView2 实例读取确认。
  - 明确清除 profile 数据后读取无 Cookie，再次重建实例仍无 Cookie。
  - 不访问真实账号、Cookie、密码或 Key；原生 helper 忽略项由主测试显式调用，不把空跑 helper 算成验证。
- 固定 profile 保留/占用锁、恢复未确认不认证、清理失败不谎报退出、取消与过时登录结果测试通过。
- `cargo clippy --workspace --all-targets -- -D warnings`、`cargo fmt --all -- --check`、`cargo build --release -p wh-desktop`：通过。

## 剩余验收边界

真实 Wallhaven 账号的跨重启登录尚需本人完成登录后核对；本地持久 Cookie 跨进程测试不等于真实网站全部认证场景已验收。安全验证间歇停留尚不能承诺根治；若网站继续不接受 WebView2，需继续保留准确错误提示并核对运行环境/网站支持，不绕过验证。

本次没有修改用户真实收藏夹或收藏，没有覆盖现有 `config.json`。
