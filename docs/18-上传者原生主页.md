# 上传者原生主页

> 本文记录最初 SFW-only 版本。后续已改为继承主界面分级并可独立选择 SFW/Sketchy/获准NSFW，原图加载并行与标题对齐见 [最新修复](20-加载提速与作者筛选标题对齐.md)；下文原始验收数字保留为历史记录。

## 本轮范围

Windows / Rust + Slint 原生实现；不是系统浏览器或内嵌网页主页。图片详情中的上传者现在是可操作按钮，读取当前 `State.detail` 的实际上传者并验证用户名后，打开独立主页窗口。无上传者或用户名不合法时不提供虚假链接。

主页包含三个页签：

- **个人资料**：公开头像、用户名、用户组、简介，以及网站实际公开的加入时间、最后活跃、上传/收藏/订阅者等统计。缺失资料不补成零；未公开简介显示明确文案。时间保留网站返回的带时区值，不凭空推算。
- **上传作品**：官方 API 的 `@username` 查询，固定 `purity=100`，独立上一页/下一页；卡片保留原图比例、同行等高排列。
- **公开收藏**：公开收藏夹列表，选择并打开内容，固定只读取 SFW；收藏夹总数是网站统计，可能包含被当前过滤条件排除的图片，因此不把数量差异说成数据丢失。

作品可在主页窗口内打开适应窗口预览并返回列表，不替换主窗口当前详情；预览不会落盘到用户图片目录。主页只保留当前作品页（最多 64 张）和最多 500 个收藏摘要，不累计整个人的原图。公开 API 通常每页 24 张，本轮真实返回也是 24 张。切换主页页签会重新加载对应列表；不承诺记忆各页签的上一次页码。

## 数据与隔离

- `public_profile.rs` 独立公开只读服务，不接触 WebView2 登录生命周期，不导出 Cookie，不携带 API Key；客户端克隆后清除 Key，继续共享限流器。
- 资料由公开 `/user/{username}` 读取，HTTP 超时、同源跳转限制、2 MiB HTML 上限；只解析匹配当前用户的资料头、简介和右侧公开信息，不展示原始 HTML，不提取评论或脚本。
- 头像只接受 Wallhaven HTTPS 头像路径；头像下载走 8 MiB 缩略图限制。作品图片限制为已知 Wallhaven CDN 地址。后续原图加载已取消旧解码内存/尺寸配额和降采样，详见 [原图内存限制修复](19-原图内存限制修复.md)；缩略图/头像的原有限制不变。
- 主页使用独立状态、列表请求代数和独立图片加载器；切换用户、页签、关闭窗口后的过期结果不能填入新列表，不调用主画廊的重置或图片任务取消。
- 新原生窗口复用 Fluent 深色、自绘标题栏与现有 Win32 命中处理。关闭主页不关闭主窗口；关闭主窗口同时隐藏主页、设置与收藏工具，正常结束进程。
- 图片预览时隐藏底下的资料/列表，避免辅助功能仍操作被遮挡的卡片。

## 保留边界

- 个人资料来自公开 HTML，不是官方稳定资料 API。网站改版、安全验证、限流或网络故障会明确报错，可刷新；不绕过验证，也不保证所有用户/网络都成功。
- 只读原生主页不含关注、私信、评论编辑或网站资料修改；不自动扩大为 Sketchy/NSFW。
- 当前网页公开简介按纯文本呈现，不执行 HTML、链接或脚本；不自动加载个人背景大图。
- 没有新增完整跨显示器 DPI/屏幕阅读器审核；本机实测与组件回归不等于所有环境验收。
- 网站间歇安全验证停留、真实站内 CRUD/收藏写入端到端验收和既有下载队列/数据库等范围保持原状态，不因原生主页完成而宣称全部 Windows 功能完成。
