## 3. 网络层设计（防腐 + 限流）

### 3.1 客户端装配

```kotlin
// shared/commonMain/data/api/HttpClientFactory.kt
expect fun buildPlatformEngine(): HttpClientEngine   // okhttp(android) / winhttp(desktop)

fun createHttpClient(config: ApiConfig): HttpClient = HttpClient(buildPlatformEngine()) {
    install(ContentNegotiation) {
        json(Json {
            ignoreUnknownKeys = true   // ★ ACL 核心：API 加字段不崩
            isLenient = true
            explicitNulls = false
            coerceInputValues = true
        })
    }
    install(HttpTimeout) { requestTimeoutMillis = 30_000; connectTimeoutMillis = 15_000 }
    defaultRequest {
        header("X-API-Key", config.apiKey)            // ★ 不放 URL，避免日志泄漏
        header(HttpHeaders.UserAgent, "WallHavenStudio/0.1 (third-party client)")
        url("https://wallhaven.cc/api/v1/")
    }
    expectSuccess = false                              // 手动处理 429/401
}
```

### 3.2 限流器（必须，否则一定被 429）

```kotlin
class TokenBucket(
    private val capacity: Int = 45,
    private val refillPerMinute: Int = 45,
    private val clock: () -> Long = { Clock.System.now().toEpochMilliseconds() }
) {
    // 令牌数 + 上次补充时间；acquire() 挂起直到有令牌
    suspend fun acquire() { /* 计算差额补充，不足则 delay 到下一个应补充时刻 */ }
}
```
**要求**：
- 全局**单例**，所有 API 调用共享
- 收到 `429` → 指数退避（2s→4s→8s，上限 60s），并**降低本分钟配额**
- 并发上限 3（多标签清洗时不宜猛冲）

### 3.3 API 接口（Domain 优先，非 JSON 直映射）

```kotlin
interface WallhavenApi {
    suspend fun search(query: SearchQuery, page: Int): PagedResult<WallpaperSummary>
    suspend fun wallpaper(id: String): WallpaperDetail
    suspend fun tag(id: Int): TagInfo
    suspend fun settings(): UserSettings?
    suspend fun collections(): List<Collection>?
    suspend fun collectionItems(user: String, id: Int, page: Int, purity: String?): PagedResult<WallpaperSummary>
}

// DTO 全字段可空 —— 官方声明"可无预警变更"
@Serializable data class WallpaperDto(
    val id: String,
    val url: String? = null,
    val path: String? = null,        // 下载直链
    val resolution: String? = null,
    val dimension_x: Int? = null,
    val dimension_y: Int? = null,
    val file_size: Long? = null,
    val file_type: String? = null,
    val purity: String? = null,
    val category: String? = null,
    val colors: List<String> = emptyList(),
    val thumbs: ThumbsDto? = null,
    val created_at: String? = null,
    val views: Long? = null,
    val favorites: Long? = null,
    val source: String? = null,
    val uploader: UploaderDto? = null,
    val tags: List<TagDto> = emptyList(),
    val short_url: String? = null,
    val ratio: String? = null,
)
```
**映射层（ACL）** 负责：可空→默认值、`file_type` 归一（`image/jpeg`→`jpg`）、`created_at` 字符串→`Instant`、坏数据丢弃并记录。

### 3.4 错误模型

```kotlin
sealed interface ApiError {
    data object Unauthorized : ApiError        // 401 → 提示 Key 无效
    data object RateLimited : ApiError         // 429 → 退避并提示
    data class Http(val code: Int) : ApiError
    data class Network(val cause: String) : ApiError
    data class Schema(val detail: String) : ApiError  // 反序列化失败 → 降级不崩
}
```
UI 层只消费 `Result<T, ApiError>`，不接触异常。

## 4. 数据层设计（SQLDelight）

### 4.1 Schema 草案

```sql
-- Wallpaper.sq
CREATE TABLE wallpaper (
    id            TEXT NOT NULL PRIMARY KEY,
    page_url      TEXT,
    image_url     TEXT,          -- path，下载直链
    resolution    TEXT,
    width         INTEGER,
    height        INTEGER,
    ratio         REAL,          -- 缺失时由 width/height 反算
    file_size     INTEGER,
    file_type     TEXT,
    purity        TEXT,
    category      TEXT,
    colors        TEXT,          -- JSON array 字符串
    thumbs_json   TEXT,
    uploader      TEXT,          -- 详情页才有
    source        TEXT,
    views         INTEGER,
    favorites     INTEGER,
    created_at    INTEGER,       -- epoch millis
    detail_loaded INTEGER NOT NULL DEFAULT 0,  -- 标签是否已抓
    fetched_at    INTEGER NOT NULL
);
CREATE INDEX idx_wallpaper_created ON wallpaper(created_at DESC);
CREATE INDEX idx_wallpaper_res     ON wallpaper(resolution);
CREATE INDEX idx_wallpaper_purity  ON wallpaper(purity, category);

-- Tag.sq
CREATE TABLE tag (
    id          INTEGER NOT NULL PRIMARY KEY,
    name        TEXT NOT NULL,
    name_norm   TEXT NOT NULL,   -- 清洗后：小写去空格，用于去重
    alias       TEXT,
    category    TEXT,
    purity      TEXT
);
CREATE UNIQUE INDEX idx_tag_norm ON tag(name_norm);

CREATE TABLE wallpaper_tag (
    wallpaper_id TEXT NOT NULL,
    tag_id       INTEGER NOT NULL,
    PRIMARY KEY (wallpaper_id, tag_id),
    FOREIGN KEY (wallpaper_id) REFERENCES wallpaper(id) ON DELETE CASCADE,
    FOREIGN KEY (tag_id)       REFERENCES tag(id)       ON DELETE CASCADE
);

-- Download.sq
CREATE TABLE download (
    wallpaper_id TEXT NOT NULL PRIMARY KEY,
    state        TEXT NOT NULL,     -- queued/downloading/paused/done/failed
    bytes_done   INTEGER NOT NULL DEFAULT 0,
    total_bytes  INTEGER,
    local_path   TEXT,
    sha256       TEXT,
    error        TEXT,
    updated_at   INTEGER NOT NULL
);

-- Sync.sq（断点续抓）
CREATE TABLE sync_cursor (
    query_key   TEXT NOT NULL PRIMARY KEY,   -- 参数规范化后的哈希
    params_json TEXT NOT NULL,
    next_page   INTEGER NOT NULL DEFAULT 1,
    last_page   INTEGER,
    total       INTEGER,
    updated_at  INTEGER NOT NULL
);

-- Collection.sq
CREATE TABLE collection (id INTEGER, owner TEXT, label TEXT, public INTEGER, count INTEGER,
    PRIMARY KEY(id, owner));
CREATE TABLE collection_item (collection_id INTEGER, owner TEXT, wallpaper_id TEXT,
    PRIMARY KEY(collection_id, owner, wallpaper_id));
```

### 4.2 单一事实来源（SSOT）

```
UI ──观察 Flow──▶ Repository ──▶ SQLDelight（唯一真相）
                        │
                        └──网络刷新──▶ 写库 ──▶ Flow 自动推送 UI
```
- **UI 永不直接读网络响应**，只读 DB Flow
- 网络成功 = 写库；DB 变化 = UI 更新
- 这样天然获得：离线可用、跨页去重、重启恢复

## 5. 图片管线（性能关键）

| 场景 | 尺寸 | 来源 | 说明 |
|---|---|---|---|
| 瀑布流列表 | 屏幕宽 ÷ 列数 | `thumbs/small` | 24px–200px 级，缓存命中率高 |
| 详情大图 | 屏幕尺寸采样 | `thumbs/large` 或 `path` | **必须传 size**，禁止 decode 原图 |
| 全屏查看 | 屏幕像素 | `path` | 允许缩放平移（`detectTransformGestures`） |
| 下载落盘 | 原始 | `path` | 流式写 + sha256 边算边存 |

**Coil 3 配置要点**：
```kotlin
ImageLoader.Builder(context)
    .components { add(KtorNetworkFetcherFactory(httpClient = shareHttpClient)) }
    .memoryCache { MemoryCache.Builder().maxSizePercent(context, 0.20).build() }
    .diskCache { DiskCache.Builder().directory(cacheDir).maxSizeBytes(512L * 1024 * 1024).build() }
    .build()
```
- 8K 图（7680×4320）解码后 ~132MB → **任何情况下不得在列表里加载**
- 列表滚动时暂停新请求（`LazyGridState.isScrollInProgress` → 用 placeholder）

**虚拟滚动**：`LazyVerticalStaggeredGrid` + `key = wallpaper.id` + 预取阈值 = 剩余 12 个 item 时触发下一页。
