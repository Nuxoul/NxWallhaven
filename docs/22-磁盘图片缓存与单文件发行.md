# 磁盘图片缓存、原图保存复用与单文件发行

## 本轮纠正

此前把绘制像素的内存复用当成图片文件缓存，未满足用户要求。本轮改为真正的本地文件缓存，下载目录与缓存目录分开。本文取代第 21 篇中“不持久化原图”的历史描述。

- 默认图片缓存：`%LOCALAPPDATA%\WallHavenStudio\Cache\Images`。
- 下载/保存：写入设置中的下载目录，即 `Settings::resolved_download_dir()`，不是写入缓存目录充当下载。
- `WH_STUDIO_CONFIG_DIR` 隔离运行时，缓存位于该目录的 `image-cache-v1`，不使用真实配置/浏览器资料目录。
- 缓存压缩图片文件；内存中的解码像素仅用于绘制，不替代磁盘缓存。
- 加载完整原图后点击下载，直接将缓存中的原始字节转存到下载目录，不发起第二次原图请求、不重新编码。
- 共享缓存采用复制而非移走，避免破坏其他窗口和后续打开时的复用。
- 原图尚在传输时点击保存，加入同一 URL 的文件传输任务，不新增一次 GET。
- 进程重启后，仍可从完整磁盘缓存读取并保存；不依赖上一进程的内存。
- 只有缓存不存在、损坏或被主动清理后，才需要重新取得该文件。列表缩略图不是完整原图，只有缩略图缓存不能代替首次原图下载。

## 实现与安全边界

主要实现：`image_disk_cache.rs`、`image_loader.rs`、`cache_control.rs`、`ui/app.slint`。

1. URL 的 SHA-256 作为缓存键；元数据记录文件长度、文件 SHA-256、版本与受限扩展名，不保存原始 URL、Key 或 Cookie。
2. 网络数据分块写入独立 `.part` 文件；完整传输、长度校验与同步后提交图片及元数据。半截响应不作为命中。
3. 磁盘命中检查长度和 SHA-256；相同长度的内容损坏也会拒绝并重新获取。
4. 同一进程内，所有加载器共享文件缓存与进行中的传输；完整解码任务另有共享机制。页面刷新只使旧页面/像素代数失效，不解绑其他窗口的文件下载。
5. 明确清理缓存时递增文件缓存代数，清理前的任务可以完成向当前调用者交付，但不能重新填回缓存。
6. 清理只在带有精确应用标记的目录内处理应用命名的普通文件，包含遗留 `.part`；不递归遍历，不跟随目录/文件链接或 junction。无关文件与子目录保留。
7. 下载写入目标目录内的临时文件，同步后以 Windows 无覆盖重命名提交。已经存在的下载文件不会被覆盖，原始缓存不会被移除。
8. 设置展示实际磁盘字节数、缓存文件数和路径，元数据/临时文件计入用量；另列“绘制缓冲”。统计和磁盘清理在工作线程完成。
9. 清理不会删除下载、壁纸、API Key、配置或 WebView2 登录资料；正在显示的图片仍可能持有绘制像素，不把缓存用量称为进程总内存。

当前没有自动容量淘汰策略，用户可在设置中清理。跨进程先后重启复用已测；多个应用进程同时写入/清理同一缓存目录不属于本轮已验证范围，不声称有跨进程传输合并或全局清理锁。

原图继续完整解码，无此前固定响应大小、边长、解码内存上限或 2000px 降采样；实际系统内存、解码器和绘制资源仍有物理边界。缩略图保留独立安全限额。

## 红绿回归与结果

初始“先加载、关闭服务器、再保存”测试曾实际失败：保存路径又请求原图，出现 `error sending request`。实现文件缓存后通过。

进一步检查发现并修复：

- 页面刷新曾解绑共享文件任务，导致另一窗口已加载原图未保存到磁盘；断网保存回归先红后绿。
- 清理曾跳过遗留 `.part`，真实用量不能归零；遗留临时文件清理回归先红后绿。
- 旧页面失效测试已改为验证“旧像素不回填，但磁盘文件可离线复用”，不再要求无意义的重复传输。
- 失败共享测试以调用者加入任务的握手替代固定 sleep，避免忙机器上的调度误判。

当前通过的关键测试：

- 原图加载后关闭本地 HTTP 服务器，保存成功，文件字节与响应完全相同。
- 新建加载器/缓存实例，服务器离线，读取和保存原图成功。
- 启动独立测试子进程，原服务器已关闭，读取磁盘并保存成功；不是同一进程内存命中。
- 原图传输中保存只收到一次 HTTP 请求，保存字节完全相同。
- 刷新其他画廊不破坏正在写入的原图缓存。
- 截断响应不留下完整缓存/临时文件，损坏的同长文件不被误用。
- 清理前的传输不会回填磁盘；清理正在打开的临时文件后，原调用仍能收到完整字节。
- 清理保留无关文件、子目录、已经保存的下载；目标文件存在时不覆盖。

结果：核心 **38 通过 / 1 忽略**，桌面 **117 通过 / 6 忽略**，共 **155 项常规测试通过，0 失败**。严格 Clippy、格式检查均通过。忽略项包含需显式运行的原生 WebView2/在线探测及子进程助手；磁盘重启助手由正常父测试显式执行，不是漏测重启。

本轮未向真实用户下载目录写入测试图片，未进行收藏写入、桌面壁纸修改、配置或登录资料清理。真实配置文件的长度与修改时间保持不变。
