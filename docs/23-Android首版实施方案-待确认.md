## 2. 模块与职责

- `composeApp`：Compose 页面、导航、触摸交互与生命周期，Android 系统动作。
- `shared`：Kotlin 状态、用例和 UniFFI 适配；不再写第二套 Wallhaven API/分级校验规则。
- `rust/core`：现有 API、模型、限流与平台无关逻辑；逐步承接跨端图片文件缓存及后续本地库规则。
- 新增 Android FFI crate：只暴露搜索、详情等少量高层接口，返回数据/错误；不暴露 Slint/Windows 类型，不通过 FFI 传完整原图 RGBA 或大字节数组。
- Rust 现有阻塞网络代码在工作线程运行，不能阻塞 Compose 主线程；Kotlin 层提供挂起调用、取消/过期结果隔离和生命周期状态恢复。
- 配置密钥由 Android Keystore 加密保护，不复用 Windows DPAPI，也不写入日志/普通偏好明文。
- Android 文件导出、WebView 会话、系统壁纸等是平台适配，不塞入通用 Rust 网络模块。

优先先证明 Rust 搜索 → UniFFI → Compose 的纵向链路可构建运行，再铺开页面。不会为“共享”一次性迁走全部桌面控制器。

## 3. 第一阶段：可安装的浏览闭环

1. **浏览与搜索**：最新/热门/随机、关键词、分类、SFW/Sketchy/NSFW、分辨率/比例等筛选；默认按原比例展示，自适应布局，统一网格作为显式设置；下拉刷新、自动续载、去重、防重复请求、失败重试。
2. **完整原图详情**：加载进度、元数据、标签/颜色检索、双指缩放、拖动、双击、分享/复制链接；返回后保留画廊位置。
3. **作者主页**：原生公开资料、作品和公开收藏；分级继承并可独立调整，滚动追加；不使用网页代替作者 UI。
4. **保存与设置壁纸**：复用缓存原图导出到相册 `Pictures/NxWallhaven`；系统支持时选择主屏/锁屏。用户选定裁切/系统壁纸结果不改写原始缓存或已保存原图。
5. **设置**：API Key、内容权限、主题、布局、缓存实际占用/清理；NSFW 默认关闭，仍需用户许可和有效 Key。安全设置变化隔离旧任务/受限内容。
6. **移动生命周期**：旋转、切后台/返回、系统回收后的合理恢复；大图解码/列表图片不占用主线程，不使用桌面式多窗口导航。

本阶段不把未验证的网站收藏写入、完整下载队列、本地图库/清洗和自动换壁纸混入首个可安装里程碑。

## 4. 文件缓存与下载：从首版就按正确模型实现

- 缩略图和完整原图均为本地图片文件缓存，建议保存在应用私有 `cacheDir/images`，操作系统可以回收。
- 相册中的下载文件由用户持有，与缓存分开；清理缓存不删除相册、设置、Key 或登录资料。
- 完整原图已在缓存时，保存直接从该文件复制到目标 URI，不重新请求、不重新编码。传输中保存加入同一任务；应用正常重启后缓存尚在即可继续复用。
- 尚未获取完整原图时，列表缩略图不代替首次原图下载。
- 采用临时文件、完整性检查和完成提交，防半截缓存；按 URL 合并请求，显示磁盘真实用量，配置合理磁盘上限与淘汰，不让缓存无限增长。
- Android 10+ 使用 MediaStore，旧系统按需申请存储权限；自定义导出目录用 SAF，不申请无必要的“所有文件访问”权限。
- Coil 如用于列表绘制，接入统一文件获取入口，避免默认网络加载形成第二套原图请求/磁盘缓存。
- 超大图直接一次解成整张 RGBA 不适合移动设备。完整压缩原图照常下载/缓存/导出；显示采用原图文件的区域解码/分块读取，随缩放解码需要区域。不能把低清缩略图当成原图，也不承诺无限内存。具体库/格式支持须在纵向原型中验证。

## 5. 第二阶段：账号与收藏

- 官方 API 的账号信息/收藏读取复用共享模型与分级规则。
- 需要站内写入的流程用 Android WebView 会话；登录、验证码由用户操作，正常重启保留会话，明确退出才清理。
- 收藏列表和管理 UI 原生实现，网页只负责必须的登录与站内会话动作。
- 站内创建/修改/删除/收藏写入先通过本地表单和丢响应等回归，再由用户授权真实账号写入验收；不把 API Key 当成网站登录，不绕过网站安全验证。
- Windows 仍有站点间歇验证和真实写入验收限制，不宣称把同样流程复制到 Android 即保证成功。

## 7. 实施顺序和验收

1. **环境与桥接**：核验 Gradle/AGP/Kotlin/CMP/NDK 组合，生成并打包 Rust `.so`，构建首个可安装 APK，验证 16KB 页兼容等原生库要求；先跑模拟器。
2. **浏览纵向链路**：用真实公开 SFW API 显示列表/详情；完成分页、返回位置与异常状态。
3. **图片闭环**：磁盘缓存、断网保存、加载中保存单请求、完整原图分块显示、分享与壁纸预览。
4. **作者与设置**：原生作者页、分级权限、缓存统计/清理、Keystore、生命周期。
5. **回归与交付**：Rust/Android 单元与组件测试、模拟器安装运行、真机验收；给出 APK、构建方式、哈希和实际验证记录，未连接真机不能写成真机通过。

第一阶段通过标准包括：

- 手机可安装/启动，而非只展示静态页面；真实搜索和自动分页可用。
- 详情完整原图及缩放正常，返回列表不跳顶，作者列表连续追加。
- 加载原图后关闭服务器/断网仍能保存；独立重启后缓存可用时仍能保存；加载中保存只产生一次文件请求；导出文件字节一致。
- 缓存统计来自文件；清理不影响已经下载到相册的文件、配置或会话。
- 不把 API Key 写入日志/普通配置；NSFW 不被默认开启。
- Windows 常规测试保持通过，没有为手机端破坏桌面。
